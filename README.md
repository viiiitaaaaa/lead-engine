# lead-engine — привлечение клиентов (коттеджные посёлки, подрядчики, инженерия)

Основной проект. Схема: `docs/schema_voronka.jpg` — все каналы (дизайн-бюро, партнёры, брокеры,
блогеры, УК и консьержи, клубы, редакции, Авито, Яндекс Карты, Telegram, YouTube, Instagram, сайт,
тендеры) сходятся в «Автоворонку кейсов» → лендинг/бот под выпуск → CRM (Bitrix24) → ИИ-оценка воронки.

## Этап 1 — парсинг
Сбор данных по коттеджным посёлкам и подрядчикам с русскоязычных сайтов (списки — от заказчицы).

## Папки
- `parsers/` — сборщики
- `data/lists/` — входные списки компаний (в git не попадают)
- `data/raw/` — сырые выгрузки (в git не попадают)
- Google Диск: `Мои задачи\Лидогенерация — коттеджи и подрядчики` — списки, выгрузки, голосовые

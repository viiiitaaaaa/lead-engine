# Сайт с нуля — всё для старта (05.10.2026)

Сайт = лендинг из схемы воронки lead-engine (каналы → лендинг/бот → Bitrix24): инженерная компания полного цикла
под ключ, только премиум-люкс, территория — Новая Рига, Рублёвка, Ильинское шоссе. Производство климата — Frivent.

## 1. Что уже решено (не пересматривать)
- **Что продаём:** архитектура, дизайн, проектирование, стройка, монтаж своими бригадами, вся инженерия дома
  (вентиляция/климат Frivent, отопление, вода, сантехника, умный дом, бассейн/СПА/хамам), стекло, текстиль, ландшафт;
  сервис, запчасти и замена любого европейского оборудования (через партнёров). Массовый сегмент — не наш.
- **Клиент:** очень богатый человек или его жена; решают за них **ассистенты** (личный помощник, управляющий домом,
  семейный офис, архитектор, технадзор). Образ жизни: умный дом, кинозал, бассейн/СПА/хамам, яхта, дома от 1000 м².
- **Один сайт для всех:** первый экран общий + выбор «Я — …» (ассистент, генподрядчик/монтажник, дизайнер/архитектор,
  владелец, застройщик, коммерция, партнёр «под ключ»); каждая кнопка → свой раздел: боль → наш ответ → доказательство → своя заявка.
- **Заявки только к нам:** UTM-метка во всех ссылках; **адрес объекта — обязательное поле формы**, бронь по адресу в CRM,
  одинаковая РРЦ; ответ на «у производителя дешевле» — цена везде одна, у нас подбор, несколько брендов и сервис.
- Партнёры: монтажные и климатические компании «под ключ», бюро премиум-сегмента. Брокеры и УК посёлков — НЕ партнёры.

## 3. Инструменты для дизайна и вёрстки (уже подключены)
- **Inspo MCP** — 832 реальных сайта: палитры, шрифты, структура страниц. Старт: `recommend` с брифом «премиум-инженерия
  для загородных домов, тихая роскошь», затем 1–2 `search_screens` и 3–5 `get_screen` — референсы.
- **Скилл site-mockups** — экраны в ComfyUI Cloud одним рецептом + принцип дизайн-системы из двух слоёв
  (ахроматическая оболочка, цвет только акцентом) — сам принцип подходит и для премиума.
- **no-ai-slop** — чистка текстов от «ИИ-шного» стиля (правила англоязычные, логика годится и для русского).
- **dataviz** — если на сайте будут цифры/графики (доля болей, спрос).
- Из новостей: Superdesign (вытаскивает стиль с сайта и рисует лендинги), курс Lovable + n8n + Supabase (slivaker_it),
  Битрикс24 «Код» — собирает лендинги прямо в Битрикс24 (заявки сразу в CRM воронки).
- Репозитории GitHub: `lead-engine` (данные и тексты — основа сайта), `artmellio-system` / `artmellio-blank-theme` /
  `artmellio-theme` — Shopify-тема магазина ARTMELLIO, **не наша** (магазин ей не принадлежит с 02.10), для этого сайта
  не использовать; `automation-scripts`, `case-bot` — не про сайт.

## 5. Порядок работы (предлагаю)
1. Структура страницы из раздела 8: первый экран + «Я — …» + 7 разделов + форма с адресом объекта.
2. Референсы через Inspo (тихая роскошь, архитектурные бюро, премиум-девелоперы) → палитра и шрифты.
3. Тексты разделов из «основы лендинга» (боль → ответ → доказательство), чистка no-ai-slop.
4. Макеты экранов → вёрстка → форма в Bitrix24 с UTM и адресом объекта.
Открытые вопросы к ней: на чём собираем (Тильда, Битрикс24, свой код), домен, фото объектов (портфолио Frivent почти всё коммерческое).

## 6. Полезное из каналов по дизайну сайтов (сбор 05.10.2026)
Каналы добавлены в ежедневный сбор новостей (tg_monitor): Intelligent Design и Сайтодел — разбираются полностью,
UX Live и Веб-страница — только полезное для сайта. Свежие карточки — блок «Дизайн сайтов» на «Рабочей панели».
Шрифты из списка — сначала проверить русские буквы и лицензию.

### Вид «дорого», палитра, шрифты, блоки
- **Готовая «дорогая» палитра: бежевый, бронза, тёмно-коричневый** ([пост](https://t.me/sitodel/3912)) — Взять как стартовую палитру лендинга: фон `#E5DFD6`, текст и тёмные блоки `#3C2418`, акцент (кнопка заявки, тонкие линии, цифры) `#B19061`. Записать в CSS как переменные и попросить Claude Code использовать только их.
- **AOS — готовые анимации появления блоков при прокрутке** ([пост](https://t.me/sitodel/3910)) — Подключить `AOS` и дать блокам лендинга одно спокойное появление (лёгкий сдвиг снизу + проявление), одинаковое везде. Для премиума — медленно и без «прыжков», разные эффекты на одной странице не смешивать.
- **Фото оживает цветом при наведении** ([пост](https://t.me/sitodel/3886)) — В сетке объектов фото держать приглушёнными или чёрно-белыми, а при наведении возвращать цвет и чуть приближать (без поворота). Так разные по цвету фотографии домов смотрятся единой серией.
- **Шрифт Plus Jakarta Sans — геометрический без засечек** ([пост](https://t.me/sitodel/3884)) — Кандидат на основной шрифт текста и меню. Перед выбором проверить, есть ли в нём русские буквы, и сравнить на нашем заголовке с `Neue Montreal`.
- **Шкала этапов с карточкой при наведении** ([пост](https://t.me/sitodel/3859)) — Так показать блок «Как мы работаем»: обследование → проект → поставка оборудования → пусконаладка → сервис. На телефоне наведения нет — там этапы должны раскрываться по нажатию или идти списком.
- **Раскрывающиеся карточки в приглушённых тонах** ([пост](https://t.me/sitodel/3853)) — Блок направлений (вентиляция, климат, осушение бассейна, инженерия, архитектура) сделать таким рядом: узкие полосы с фото, активная раскрывается и показывает текст. На телефоне — вертикальный список с раскрытием по нажатию.
- **Анимированная иконка меню для телефона** ([пост](https://t.me/sitodel/3838)) — В мобильной версии меню спрятать под такую иконку, выбрать самый спокойный вариант (простое превращение в крестик). В раскрытом меню обязательно оставить телефон и кнопку заявки.
- **Карточки с кнопкой, «вырезанной» в углу фото** ([пост](https://t.me/sitodel/3815)) — Использовать для карточек реализованных объектов: крупное фото дома и аккуратная кнопка-стрелка «смотреть проект» в вырезанном углу. Выглядит как ручная работа, а не шаблон.
- **Восемь hover-эффектов для заголовков** ([пост](https://t.me/sitodel/3758)) — Взять один самый сдержанный эффект, действующий на слово целиком, для пунктов меню и названий проектов. Буквы «врассыпную» для премиума не подходят.
- **Шрифт Neue Montreal — нейтральный, для мелкого текста** ([пост](https://t.me/sitodel/3756)) — Кандидат для основного текста, подписей и формы заявки: нейтральный шрифт не спорит с фотографиями домов. Проверить наличие кириллицы и условия лицензии до подключения.
- **Бесконечная бегущая строка** ([пост](https://t.me/sitodel/3750)) — Одна тонкая строка на странице: марки оборудования или типы объектов (резиденция, бассейн, винный погреб, спа). Медленно, мелким шрифтом, с остановкой при наведении. Больше одной такой строки не делать.
- **Как выглядит «дорого»: зерно, мягкие градиенты, крупный заголовок** ([пост](https://t.me/sitodel/3742)) — Первый экран собрать по этой формуле: один очень крупный заголовок, короткий абзац мелким шрифтом, фон приглушённый с едва заметным зерном. Яркие цвета и много текста на первом экране не ставить.
- **Мелочь в кнопке дала Яндексу +5% заказов** ([пост](https://t.me/uxlive/18445)) — В форме заявки оставить минимум полей (имя, телефон), включить автоподстановку браузера (атрибуты `autocomplete="name"` и `autocomplete="tel"`, тип поля `tel`), на кнопку поставить понятный значок и конкретную подпись вместо «Отправить».
- **Сайт на своём коде, собранный ИИ-агентом: правки превращать в правила** ([пост](https://t.me/uxlive/18411)) — Каждую дизайн-правку по лендингу сразу записывать правилом в файл проекта `CLAUDE.md` (шрифты, отступы, палитра, тон текста), чтобы Claude Code не повторял ошибку на следующих блоках.
- **Почему «светло и просто» выглядит дёшево — и как сделать тоньше** ([пост](https://t.me/intelligentdesign/3658)) — Не делать фон чисто белым `#FFFFFF` — взять тёплый оттенок; добавить фактуру (лёгкое зерно, фото материалов) и мягкие тени. Минимализм лендинга собирать из нюансов, а не из пустоты.
- **Формула спокойной палитры: 1 базовый + 2 поддерживающих + 1 акцент** ([пост](https://t.me/intelligentdesign/3643)) — Ограничить палитру сайта четырьмя цветами по этой формуле: базовый тёплый фон, два поддерживающих (тёмный для текста и промежуточный для плашек), один акцент только для кнопки заявки и ключевых деталей. Проверять сочетание на готовом экране, а не на образцах.
- **Редактор дизайн-системы для ИИ** ([пост](https://t.me/vibecoding_tg/3994)) — после выбора палитры и шрифтов собрать `DESIGN.md` в https://app.initium.sh/ и положить в проект: Claude Code будет верстать все экраны в одном стиле.

### Правила вёрстки для Claude Code
- **Картинки: сначала размер, потом формат** ([пост](https://t.me/tproger_web/6562)) — У нас сайт держится на больших фото домов и интерьеров. Попросить Claude Code при сборке: каждое фото уменьшить до реального размера блока, сделать 2–3 варианта в `srcset`, сохранить в AVIF/WebP с запасным JPEG, логотип и иконки — в SVG.
- **Приёмы CSS для выразительного текста** ([пост](https://t.me/tproger_web/6554)) — Для главного заголовка первого экрана попробовать `background-clip: text` — буквы, залитые фото интерьера или мягким градиентом. Вертикальное центрирование в плашках делать через `align-content: center`.
- **После правки CSS силами ИИ — проверять состояния** ([пост](https://t.me/tproger_web/6526)) — Правило работы с Claude Code: после любой «чистки» или переписывания стилей проверять не только обычный вид, но и наведение, активные состояния, длинные тексты, открытое меню и ошибки формы.
- **Контур фокуса: не убирать outline ради тени** ([пост](https://t.me/tproger_web/6521)) — В стилях кнопок и полей формы заявки запретить Claude Code `outline: none`; использовать прозрачный контур плюс нашу тень. Проверить форму клавишей Tab.
- **Запасной шрифт надо писать при каждом font-family** ([пост](https://t.me/tproger_web/6518)) — В CSS-переменных со шрифтами сайта после имени фирменного шрифта всегда ставить запасной (`serif` или `sans-serif`), в том числе у заголовков. Проверить у Claude Code каждое место, где задан `font-family`.
- **Готовый CSS reset для старта нового проекта** ([пост](https://t.me/tproger_web/6514)) — Мы начинаем с нуля — самое время. Попросить Claude Code положить в начало стилей «modern CSS reset от Josh W. Comeau» и строить вёрстку поверх него.
- **Плавные анимации: не трогать размеры и положение** ([пост](https://t.me/tproger_web/6507)) — Правило для Claude Code: в анимациях появления блоков и наведения не менять `width`/`height`/`top`/`left`; если что-то дёргается — проверять в DevTools, какие этапы запускает анимация.
- **Правильная HTML-разметка: header, nav, main, alt** ([пост](https://t.me/tproger_web/6487)) — Попросить Claude Code верстать на смысловых тегах (`header`, `nav`, `main`), дать осмысленный `alt` каждому фото и прогнать готовую страницу через `html-validate`.
- **ИИ-поисковики видят только начальный HTML** ([пост](https://t.me/tproger_web/6465)) — Весь текст лендинга (услуги, преимущества, контакты) писать прямо в HTML, а не подставлять скриптом. После выкладки попросить Claude Code скачать страницу через `curl` и убедиться, что тексты на месте.
- **Появление элементов по очереди одной строкой CSS** ([пост](https://t.me/tproger_web/6452)) — Карточки услуг, этапы работы, фото проектов выводить «лесенкой» через `animation-delay: calc(sibling-index() * 80ms)` — без JavaScript и без ручной нумерации элементов.
- **Ambient CSS: один источник света — согласованные тени** ([пост](https://t.me/tproger_web/6444)) — Посмотреть демо с компьютера. Если объём выглядит дорого — подключить `@ambientcss/css` для карточек и кнопок; если нет — взять сам принцип: один источник света и одинаковое направление всех теней на сайте.

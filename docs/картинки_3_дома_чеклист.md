## Как скачивать из Gemini (грабля 12.10)
Кнопка «Скачать в полном размере» в этой вкладке часто НЕ сохраняет файл (Gemini получает картинку, но не отдаёт загрузку).
Рабочий приём: перехватить fetch на googleusercontent.com/rd-gg → blob → своя ссылка <a download="имя.jpg"> (window.__saveAs).

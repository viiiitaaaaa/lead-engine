# ТЗ для сбора (Perplexity) — премиальные КП Новорижского шоссе (до 50 км от МКАД)
Для компании: отделка, инженерия, комплектация элитных домов.
Старт: Миллениум Парк, Ренессанс Парк, Мэдисон Парк, Футура Парк, Гринфилд, посёлки Villagio Estate (+ все премиальные по Я.Картам, 2ГИС, Циан, агрегаторам).

По каждому посёлку: название, км от МКАД, сайт; застройщик (юрлицо, сайт, контакты, отдел продаж); стадия, участков/домов, цены;
формат домов (подряд застройщика / участок без подряда — кто делает отделку); УК и контакты; чаты жителей (TG, WhatsApp, VK, FORUMHOUSE);
новостные каналы и СМИ; отзывы — жалобы (стройка, отделка, инженерия, поставки); подрядчики, уже работающие в посёлке.
Формат: таблица, строка = посёлок, у каждого факта ссылка; нет данных — «не найдено».
Советы: по 5–7 посёлков за запрос; проверять ссылки/телефоны; боли — отдельным запросом.

## Ключевые слова
Чаты посёлков: «[посёлок] чат / жители / Telegram / отзывы жителей / форум», «КП Новорижское чат», «коттеджные посёлки Новая Рига Telegram».
Конкуренты (Instagram, Telegram): отделка домов под ключ Новая Рига; ремонт коттеджей премиум; дизайн интерьера загородного дома; комплектация дома под ключ;
инженерные системы коттеджа; водоподготовка для дома; вентиляция загородного дома; умный дом коттедж; итальянская мебель под заказ; европейская сантехника поставки;
#новаярига #отделкакоттеджа #интерьерзагородногодома #домподключ
Боли: «подрядчик сорвал сроки отделки», «брак отделки коттеджа», «где купить европейское оборудование после санкций», «оригинал или подделка сантехника»,
«кто отвечает за инженерию в доме», «перерасход бюджета ремонт».

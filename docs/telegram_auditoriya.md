# Telegram: где сидит аудитория посёлков (правило от 30.09.2026)

**Жителям не пишем** — не стиль компании. Участники чатов нужны только для анализа аудитории.

Telegram не показывает подписки человека, у каналов не видно подписчиков → считаем **пересечения групп**:
1. Участники открытых чатов посёлков (`agentx/telegram-member-scraper`).
2. Группы-кандидаты по ключевым словам (`lofomachines/telegram-keyword-search-scraper`): ремонт, дизайн, загородная жизнь, дети, спорт, авто…
3. Участники кандидатов → доля жителей посёлка в каждой группе.

Данные: храним только хэш user_id (без имён, username, телефонов); в итоге — группы и проценты.
Итог нужен для: где размещать кейсы, с какими группами/админами партнёриться.

## Темы групп-кандидатов от Андрея Шишканова (30.09.2026)

Аудитория — владельцы недвижимости и их семьи. Территория: **Рублёвка, Ильинское ш., Новая Рига**.
Ключевые слова для поиска чатов/пабликов (шаг 2), в каждом — с привязкой к территории:
- недвижимость: застройщики, ЖК, посёлки, деревни, риэлторы, управляющие компании;
- стройка: ландшафт, архитектура, дизайн, инженерия, инженеры, прорабы, мебель, текстиль/оформление интерьера;
- семья и быт: мамочки, премиальные школы и сады, питомцы;
- стиль жизни: бьюти, фэшн, фитнес, спа, гольф, яхт-клубы, бизнес-джеты, рестораны, казино, сигарные клубы,
  «клуб миллиардеров», антиквариат, автомобили.
Правило то же: жителям не пишем, считаем пересечения групп; УК, прорабы, дизайнеры, мебель — ещё и кандидаты в партнёры.

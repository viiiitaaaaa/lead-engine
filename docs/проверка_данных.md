# Журнал перепроверки данных (03.10.2026)

Причина: вывод по «Велес Строю» (53% минусов) оказался ошибкой — отзывы 2ГИС взяты у тёзки «Велесстрой» (нефтегаз, Усть-Луга),
карточка совпала только по названию. Её просьба: перепроверить всю информацию.
